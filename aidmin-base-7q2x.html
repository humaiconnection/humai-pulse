🔑 GitHub connection

Traffic data is private to the repo owner, so paste a token once — it stays in this browser only (localStorage), never in the repo.
Make a token: GitHub → Settings → Developer settings → Personal access tokens → Tokens (classic) → Generate new → give it repo scope (traffic needs push-level access) → copy the ghp_… value and paste it here.
